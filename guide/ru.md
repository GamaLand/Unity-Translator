# Руководство пользователя UnityTranslator

## Установка и язык

В Windows x64 распакуйте **весь** ZIP приложения в отдельную папку и запустите
`UnityTranslator.exe`. Готовому пакету не требуется Python. Запуск из исходного кода:

```powershell
uv sync --locked --extra ui
uv run --extra ui unitytranslator gui
```

По умолчанию интерфейс английский. В меню **Language** рядом с **Help** доступны восемь
языков. Выбор применяется при следующем запуске и не меняет языки исходного текста и
перевода в проекте.

## Перевод

1. **Проект:** выберите папку игры, отдельную папку проекта и коды языков. Откройте
   существующий проект, чтобы продолжить работу.
2. **Тексты:** проверьте совместимость, выберите поддерживаемый источник и извлеките
   тексты. Поддержка извлечения и установки проверяется отдельно.
3. **Модель:** самостоятельно запустите LM Studio или llama-server и загрузите модель.
   Укажите локальный адрес и идентификатор модели, затем проверьте соединение.
4. **Словарь:** при необходимости добавьте сохраняемые имена, термины и правила стиля.
5. **Перевод:** сначала выполните и оцените репрезентативный пилотный перевод, затем
   запускайте основной. Доступно 1–16 параллельных запросов в зависимости от мощности
   сервера. Сворачивание окна не останавливает работу. Пауза ожидает активные запросы;
   отмена прерывает задачи клиента.
6. **Проверка:** сравните тексты, внесите правки, сохраните и отдельно одобрите перевод.
   Сохранение черновика не означает одобрения. Одобрение страницы касается выбранных
   подходящих записей. Чтобы одобрить всё, сначала подтвердите количество и предупреждения,
   затем введите показанную фразу точно и нажмите последнюю кнопку. На обоих этапах
   можно отказаться. Черновики и ошибки формата исключаются; изменение списка отменяет
   всю операцию без частичного одобрения.

## Резервная копия, установка и передача

Экспортируйте JSON или создайте резервную копию проекта. Закройте игру, подготовьте план
установки, проверьте новые файлы и отдельно подтвердите установку. Самостоятельно запустите
игру и проверьте символы, размещение и смысл текста. Применение к игре экспериментальное.

Удаляйте добавленные файлы через исходный проект. Не перезаписывайте и не удаляйте вслепую
`winhttp.dll`/`doorstop_config.ini`, не сбрасывайте исходную опись файлов.
См. [руководство разработчика](../docs/installation.md).

Получатель распространяемого ZIP выбирает папку соответствующей версии игры через
`Kur.cmd`. `Kaldir.cmd` удаляет только принадлежащие пакету неизменённые файлы. Модель и
UnityTranslator получателю не нужны. Сохраняйте вложенные лицензии и исходные материалы.
Поддерживаются не все игры Unity; автоматические проверки не гарантируют качество.
Некоторые технические сообщения остаются на исходном языке.


Языки исходного и переводного текста игры не зависят от языка интерфейса. Используйте ja для японского, it для итальянского или pt-BR для бразильского португальского; можно ввести и другие коды. Исходный язык должен присутствовать в игре. Отсутствующие и неоднозначные столбцы отклоняются. Модель должна поддерживать языковую пару. Языки, одобрения и правила стиля существующих проектов сохраняются; проверьте старые правила, привязанные к языку. Перед распространением проверьте шрифты, RTL и формы множественного числа на небольшом патче. Английский также может быть целевым языком.

## Krypta FM

Для проверенной версии выберите исходный язык `en` и извлеките тексты обычным способом. Профиль читает три контейнера вместе: 34 TextAsset, 442 поля. Два источника явно исключены; другие тексты остаются вне профиля. После перевода, проверки и одобрения экспортируйте одобренные тексты TextAsset. В проекте создаются подготовленные текстовые файлы и манифест; неодобренные поля сохраняют исходный текст. Файлы Unity не изменяются, перевод в игру не устанавливается. Установка для этого профиля не поддерживается. Закройте старые версии приложения перед открытием проекта схемы 5.

В дополнительных настройках можно отключить рассуждения для запросов LM Studio, чтобы оставить больше выходных токенов для перевода. Поддержка зависит от загруженной модели и сервера; неподдерживаемая настройка может остановить задание. Значения по умолчанию и общие настройки сервера сохраняются.

Версия профиля 2 также читает семь английских задач дневника из статических метаданных: всего 449 полей в 34 TextAsset и одной таблице дневника. Прежние идентификаторы и одобрения сохраняются. Новый перехватчик дневника пока проверен только компиляцией и синтетическими тестами; прежний пилот из трёх пунктов меню наблюдался в игре. Обычная установка Krypta через интерфейс пока не поддерживается.
